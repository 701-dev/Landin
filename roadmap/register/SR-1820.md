`install.sh` refuses FreeBSD ("no release archive serves FreeBSD on amd64") and names nix and the source build, though from the release after 0.2.11 the release workflow publishes a FreeBSD x86-64 archive, so a FreeBSD user is sent to a source build of a compiler whose archive is on the releases page. Met adding that archive on 2026-11-24, when no release yet held it to test the script against; `docs/capabilities.md` says to unpack it by hand meanwhile.

Completion: `install.sh` installs the FreeBSD x86-64 archive, `--list` names it, and `scripts/tests/test_install_script.py` holds both, with a release that has the archive.
