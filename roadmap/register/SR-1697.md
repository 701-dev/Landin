The repository cannot be checked out on Windows: `compiler/tests/debugging/caller"\path.ldn`, a debugger case's source whose name holds a double quote and a backslash, is a path Git for Windows refuses, even outside a sparse checkout, so `actions/checkout` fails on a Windows runner. R21.10 met it in run 45176153194 and routed around it, the `windows-runtime` job taking its lane from the bundle and checking nothing out; a Windows contributor's `git clone` fails the same way.

Completion: the case makes its awkward path at run time, in a temporary directory, rather than keeping it in the tree, and a Windows runner checks the repository out.

Kept: aged past ten by R21.60, which made refine build and run on FreeBSD x86-64 and checked the repository out on no Windows host.
