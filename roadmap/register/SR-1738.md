The library page's reader refuses a public `extern(c) link(symbol: ...)` declaration whose name stands on the next line, a layout the formatter accepts and long kernel32 names need, and refuses a public declaration that shares one `---` comment with the line above, with "unsupported public declaration" or "undocumented public" naming only the first such line it meets. R21.20 met both writing `platform/windows`, found the rest one `check.py` run at a time, and put every extern head on one line instead.

Completion: the reader takes a declaration's name from its next line, and its refusal lists every declaration it refuses in one run.
