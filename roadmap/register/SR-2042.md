On arm64 a loop whose head block is emitted after its cold path takes cycles from where that head falls: R16.44 removed one `adds` and `b.cs` from reverse-complement's `write_reversed` loop, 4.26% fewer instructions, and the program then took 1.57% more cycles on a Cortex-X925 core of kithinkstation02 (perf, user cycles, median of seven, every run of the candidate above every run of the base). The one instruction removed lies before `.L5_6`, the `at > 0` test the loop jumps back to, which is emitted after the `io.put` path and so moved by four bytes; the loop's body and its head are far apart. x86-64 took 1.88% fewer cycles for the same change.

Completion: the head of such a loop placed beside its body, or aligned, on arm64, and the program measured in cycles against the base.
