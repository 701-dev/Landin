The backend suite's `narrow ranges use scalar comparisons` pinned how Cortex-M emits a `Range_Check` whose bounds cover only part of its scalar, eliding the comparison a bound at the type's edge makes unnecessary. It compiled a range subtype to get one, and went with range subtypes in R19.70 (D1661). The emission code stays, since conversions and pointer-address checks still lower to `Range_Check`, but no case now reaches the partial-bound paths, so a regression there would pass the suite.

Completion: A backend case built from IR directly, or from a source that still lowers to a partial-bound `Range_Check`, pinning each elided comparison, or the paths removed as unreachable.
