`refine run --root=. compiler/tests/fixtures/runtime/example-dice-and-cards/main.ldn 2026`, giving the example program its seed, is refused with L0002, "a rooted request names one entry-module directory, or the entry module's source files", which reads as if the program's path were wrong. The program's arguments go after `--` (`... main.ldn -- 2026`), which the refusal does not say. Met in R22.42 running the dice example with a seed.

Completion: An operand after a rooted `refine run`'s program that names no source file is refused saying that a program's arguments follow `--`, or is passed to the program.
