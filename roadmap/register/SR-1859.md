`python3 check.py` reads every Markdown file under the checkout, an untracked one too, so a scratch file kept at a worktree's root fails the full check: R21.70's driver stream kept the `NOTES.md` its brief asked for there ("untracked, never committed"), and the check refused it seven times, for naming roadmap identities and for no document linking to it, while every tracked file was clean. The stream moved the file aside for each full run. Neither the brief nor `docs/process.md` says where an untracked note may live, and the refusal does not say the file is untracked.

Completion: a full `check.py` either leaves untracked files alone or names a place for a stream's notes that it does not read, and the briefs' convention matches it.
