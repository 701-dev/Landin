`math.log_gamma` below -2 is msun's reflection, log(π / |x sin(πx)|) - log_gamma(-x), which subtracts two nearly equal logarithms near each point where the function is zero, so its relative error there grows to some 10^5 ulp at both widths; above -2 it is within 4.2 ulp. The `math-log-gamma` fixtures draw negative inputs from (-2, 0) only, and the doc comment says so. CORE-MATH's lgamma expands around those zeros.

Completion: `log_gamma` within a stated few ulp for every finite `x`, its fixtures drawing from below -2.
