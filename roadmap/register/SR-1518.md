A `refine` built by a GNAT whose triple names musl refuses every compile without `--target`: `error[L0004]: no --target given, and no target describes this compiler's host, x86_64-alpine-linux-musl`. The musl spike met it building with Alpine 3.24's GNAT 15.2, and changed `Is_Linux` on its branch to accept `-linux-musl`. The host target comes from `Standard'Target_Name`, the triple of the GNAT that built `refine`, so the compiler's default target depends on which C library its builder's GNAT was configured for, although a Linux program `refine` emits makes its system calls itself and needs no C library unless it is linked with `--link=libc`. The refusal names the triple and not what to do, which is `--target=linux-x86-64`.

Completion: a Linux triple names its Linux target whatever C library it ends in, `-gnu` or `-musl`, with a case holding both; or the refusal names the target to give.

Kept: R20.50, the window item that took it past ten items, renamed library names on the breaking list and touched no compiler source; its activation is a change to target selection or a musl build, which no item of R20 makes.
