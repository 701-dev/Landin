An integer converted to a pointer by writing the pointer type as the callee, `mut seen: ptr mut [2]u32 = ptr mut [2]u32(0)`, is refused as L0301, "this text conversion requires an exact byte or text view", with the note "[0310]/[0600]: text conversion is explicit and preserves its source storage". Nothing in it is text: the spelling [0470] wants is the context-typed `ptr(0)`, and the refusal names neither it nor [0470]. Met writing a test program for R19.30; the spelling came from grepping the runtime fixtures.

Completion: a pointer type applied as a conversion is refused naming `ptr(value)` and [0470], with a negative fixture.

Kept: aged past ten by the breaking window's items (SR-1548); R20.40 moved library layers and touched no target selection, signature refusal or conversion refusal it records.
