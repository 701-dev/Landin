Values are block-local, so a loop remakes every constant and invariant it reads in each iteration: after D2092 mandelbrot's `in_set` still loads `4.0` from the constant pool every iteration (its comparison swaps operands, so the constant is the register side), and a loop's bound kept in a slot is reloaded where registers run out. Nothing hoists a value out of a loop.

Completion: Loop-invariant values made once before the loop and held across it where registers allow, measured on mandelbrot and SHA-256.
