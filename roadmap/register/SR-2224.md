`python3 scripts/assemble_targets.py REFINE .`, the command `docs/process.md` gives for whether a backend change's emission still assembles for the targets this host cannot run, exits 1 at a clean base with two faults: `positive/description-copies-text-into-ram` and `positive/firmware-image-from-a-handler` on `cortex-m0` are "refused:1, which is not an expected refusal: error[L0502]: vector placement requires an explicit --firmware-entry=NAME request". Both fixtures name their entry in `args` (`--firmware-entry=start`), which `scripts/emit_manifest.py` reads and passes on and `assemble_targets.py` does not. Met closing R16.45 on 2026-11-28; the base compiler gives the same two faults, so the run's exit status says nothing about the change.
