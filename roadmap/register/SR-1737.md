A program over the portable concepts cannot learn its own path: `io.argument(0)` is the first argument after the program's name, and only `platform/posix`'s `program_name` gives `argv[0]`, on POSIX alone. R21.20's events stream met it writing a Windows fixture whose child was to be the fixture itself, and started the command processor `ComSpec` names instead; a portable test or tool that re-executes itself, as a supervisor or a sandboxed worker does, has no way to.

Completion: `io.process` or a hosted provider names the program as it was started, on every hosted system, Windows' `GetModuleFileNameW` among them, and a fixture starts itself through it.
