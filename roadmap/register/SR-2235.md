`check.py` asks `git check-ignore` which paths Git ignores with a 30-second timeout, and on a loaded host that timeout expires: the check then fails, and `item.py push` refuses the tree as if a document were wrong. Met by R22.21 and R22.29 in batch-1 on the shared host; running the same push again passed. The refusal names the timeout, not the host's load, and does not say that running it again is the answer.

Completion: a timeout that a loaded host keeps, or a retry before the check fails, or the refusal saying that the host was too slow to answer, and not the tree.
