`pkill -f PATTERN` aimed at a waiting loop kills the shell that runs it, because that shell's own command line holds the pattern, the same trap AGENTS.md describes for `pgrep -f` in a wait. Met by R22.22 and R22.44 in batch-1, each of which lost its command. AGENTS.md and the local feedback recipe warn only about `pgrep -f`.

Completion: AGENTS.md or the local feedback recipe naming `pkill -f` beside `pgrep -f`, with the way to stop a run that `run_logged.py` started.
