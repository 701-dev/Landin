Deleting a probe branch with `git push origin --delete probe/...` fails with "failed to push some refs to git.sr.ht": `origin` also pushes to the sr.ht mirror, where a probe branch never was, so the delete reports a failure although GitHub's branch is gone. Met by R22.28's streams removing their probe branches; they pushed to GitHub's URL directly to see it succeed.

Completion: deleting a probe branch reports success, by a recipe that names GitHub's remote or a mirror that ignores a branch it lacks.
