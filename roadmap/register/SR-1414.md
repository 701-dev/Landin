A program cannot ask how much memory it holds: neither `hosted/heap` nor `core/io` reports the heap's bytes in use or the process's peak size, while `core/pool` keeps counters. A test that repeated work does not grow cannot be written in Landin; refine-build measures it with GNU `time -f %M` around its executable, skipped where that program is missing. Met writing refine-build (friction entry 14).
