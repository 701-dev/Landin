D3014 puts an immutable module value in its target's read-only section on every target, but on a hosted target one whose image names another symbol, a function, an address, a slice's source or a field's target, stays in a writable `.data`: a write through an unchecked pointer still changes it silently. `.data.rel.ro` and Mach-O's `__DATA_CONST` are read-only once a loader has written them, but R22.32 did not establish that each hosted link mode has a loader that does so.

Completion: every hosted target places a relocated immutable module value where it is read-only once the program runs, with a fixture whose write faults on each, or the link mode that cannot recorded.
