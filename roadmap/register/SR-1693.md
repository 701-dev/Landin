A qualified name whose prefix is a library module no import of the program reaches, `text.bytes(value)` in a program that imports `core/text` nowhere, is still L0201 with [1860]'s note to check the spelling. D2174 names the missing import only for a module the program reaches, because the module table holds only those and the stages do not ask the host which directories the library has. Met making R20.61's notes, where a newcomer's first `text.` or `mem.` without its import is exactly the case left out.

Completion: L0201 at such a prefix names the library module and offers its import, the driver handing the stages the library's module names (or the loader resolving the prefix as an import on a refusal), pinned by a negative fixture whose program imports nothing of the module; or the reason recorded.
