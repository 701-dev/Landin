Nothing times one hand-made image or a placement variant on a board: `timing.py remote` takes only a bundle `timing.py build` wrote, so timing the same code moved by a few bytes, or linked into another RAM, means writing a bundle's `timing.json` by hand, with each image's loaded digest, ELF hash, status, checksum and placement, and a workload name that serves only as a label. Met timing 74 variants of STM32H753 images for the H753 slowdown investigation (`~/roadmap3/h753-slowdowns.md`), where an offset sweep and an ITCM/DTCM layout were what separated the code from its placement.

Completion: `timing.py` times named ELF files on a board, or the bundle format and how to make one by hand are documented, or the reason recorded.
