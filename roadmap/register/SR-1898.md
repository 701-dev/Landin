R22.10 ported msun's methods, and msun leaves several routines above one ulp, each stated in its doc comment: `sinh`, `cosh`, `tanh`, `asinh`, `acosh` and `atanh` up to 2.5 ulp, `erfc` 3.2, `log_gamma` 4.2 above -2, `atan2` 1.4, which rounds `y / x` before the arctangent, and `hypot` at f32 1.05. Each can be brought below an ulp the way the others are, carrying a rounding's error into the next step, or for f32 by computing in f64, which costs Cortex-M0 the double soft float.

Completion: each of these within an ulp, measured as the others are, with its Cortex-M0 size measured before and after.
