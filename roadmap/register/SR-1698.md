No lane measures a Windows image: `compiler/tests/measure/runners.json` gives `windows-x86-64` the `limit` class at every level, so `measure.py` records no size, wall time or instruction count for it and no baseline holds one. The Windows lane runs the corpus and measures nothing; R21.10 met the gap when the boards dispatch's timing jobs refused a target with no row.

Completion: the Windows lane measures its images' sections as the FreeBSD size jobs do, and the row names that class.
