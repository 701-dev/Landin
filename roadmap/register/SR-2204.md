`./scripts/dev-test.sh --cases=SUITE` builds the compiler and the test program before it lists a suite's cases, from clean in a new worktree, which is minutes and, since the heavy-job slots, a slot; its usage says only that it "lists that suite's cases and runs none", and `docs/process.md` recommends it for reading a brief's exact selectors. Met in R22.39, reading a suite's case names in a fresh worktree to choose local selectors. `--help` reads the suite names from the source without a build; the case names live in the test program's registrations, so a listing without a build would need them read from source the same way.

Completion: the usage says that `--cases` builds first, or the case names are listed without a build, or the reason recorded.
