A routine that returns nothing is written `-> none`, and neither refusal a newcomer meets on the way says so. `f: (inout row: [2]u32) =` is L0103, "a signature says what it returns after `->`, not `=`", whose note describes the returns but names no spelling for none; the natural next try, `f: (inout row: [2]u32) -> () =`, is L0100, "a name belongs here", with a cascade of "this function is never closed". Met writing a test program for R19.30; the spelling came from grepping the fixtures.

Completion: either refusal names `-> none` when the parameter list is followed by `=` or by `()`, with a negative fixture for each.
