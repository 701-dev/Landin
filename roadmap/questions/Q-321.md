# Q-321 — Does a program that links `core/unicode`'s tables carry Unicode's notice?

Asked by R22.30 on 2026-11-26.

R22.30 generates `core/unicode/tables.ldn` from the Unicode Character
Database, whose files are under the Unicode License V3: anyone may use,
copy, modify and distribute the Data Files, "provided that either (a) this
copyright and permission notice appear with all copies of the Data Files or
Software, or (b) this copyright and permission notice appear in associated
Documentation". The generated tables are the database's values in another
layout, and a program that calls `core/unicode` links the ones it reaches.
`LICENSE` promises that linking `core/*` places no condition on a program.
Whether a compiled table is a copy of the Data Files, and so whether that
promise holds for `core/unicode`, is a licensing judgement, which is the
maintainer's.

**Options:**

1. Keep the notice with the source, `core/unicode/LICENSE.unicode` and the
   header of `tables.ldn`, list it among `LICENSE`'s third-party material,
   and keep the promise: a compiled program carries values, not the Data
   Files, as Go's and Rust's standard libraries treat their Unicode tables.
2. Keep the notice with the source as in 1, and say in `LICENSE` and in
   `core/unicode`'s opening comment that a program linking its tables
   reproduces Unicode's notice in its documentation, which clause (b)
   allows.
3. Ask Unicode, Inc. which reading it intends before a release names
   `core/unicode`.

**Recommendation:** option 1, the reading of the standard libraries that
ship the same tables, with option 3 if a user or a distributor asks.

**Default until answered:** the notice is kept with the source, in
`core/unicode/LICENSE.unicode` and `tables.ldn`'s header, and `LICENSE`
names it among the third-party material without changing its promise.

**What waits on the answer:** nothing in the code; the wording of
`LICENSE` before a release names `core/unicode`.

**Answer (2026-11-26, the maintainer):** option 1: the notice stays with
the source, in `core/unicode/LICENSE.unicode` and `tables.ldn`'s header,
and `LICENSE` lists it among the third-party material without changing
its promise. D2734's rule covers it; the tree already agrees.
