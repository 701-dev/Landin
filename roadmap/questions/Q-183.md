# Q-183 — Should a `match` arm name a declared atom set, or should the refusals say how to split one?

Asked by R17.10 on 2026-11-22, for the register sweep of that day.

The sweep is no item and cites the item that set the register's rules.

SR-1609: R20.40's `system.words` takes `posix.errno | failure.reason` and
names each of `failure.reason`'s forty atoms in an arm of its own, since no
arm can name a set; and a comparison with one atom does not narrow either
(D189, D434), with L0301's note not naming `match` and `_ (rest):`. The row
offers two completions, one a language change.

**Options:**

1. The refusals and [1210] say how a union is split: naming one side's
   atoms with `_ (rest):`, in L0333's note for an arm naming a set and in
   L0301's at an atom subject wider than the set required.
2. A language change in the R20 window: an arm may name a declared atom
   set and binds the subject narrowed to it.
3. Keep the row as it is.

**Recommendation:** option 1, on R20.61 if Q-182 adds it; option 2 only
when a second program wants it.

**Default until answered:** the language stays as it is and SR-1609 stays
open.

**What waits on the answer:** nothing.

**Answer (2026-11-22, the maintainer):** option 1, given in the roadmap
manager's chat and relayed to the sweep. No new form: R20.61 makes [1210]
and the L0333 and L0301 notes say how a union of atom sets is split, and
takes SR-1609. Closed.
