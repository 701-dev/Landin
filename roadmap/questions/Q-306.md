# Q-306 — May `core/math` carry code ported from FreeBSD's msun under Sun's notice?

Asked by R22.10 on 2026-11-25.

R22.10 ports the elementary functions from FreeBSD's msun, as its text
says. `LICENSE` promises that linking `core/*` places no condition on a
program, so the port takes only msun files under Sun's notice, "Permission
to use, copy, modify, and distribute this software is freely granted,
provided that this notice is preserved", which asks that the notice stay
with the source and asks nothing of a compiled program. `core/math/math.ldn`
preserves it for the module. The msun files under BSD-2-Clause or
BSD-3-Clause (`s_exp2.c`, `s_fma.c`, `bsdsrc/b_tgamma.c`), whose second
clause asks a binary's documentation to reproduce the notice, and musl's
MIT-licensed routines, whose notice must go with "substantial portions",
are not ported: `exp2`, `fma` and `gamma` are written here instead.

**Options:**

1. Keep the Sun-notice port as written, and list it among `LICENSE`'s
   third-party material as preserved in `core/math`, with no condition on
   a program that links it.
2. Also admit BSD-2-Clause and MIT sources, and say in `LICENSE` that a
   program linking `core/math` reproduces their notices.
3. Write every routine from the mathematics, porting nothing.

**Recommendation:** option 1. It keeps `LICENSE`'s promise and costs only
the three routines written here, each measured as the ported ones are.

**Default until answered:** option 1: `core/math` holds msun code under
Sun's notice alone, preserved in its source and named in `LICENSE`, and
places no condition on a program.

**What waits on the answer:** nothing; another answer replaces routines
before a release names them.
